# 비공개 배포 (제한 배포 계정)

구글 개발자 인증의 제한 배포(Limited Distribution) 계정으로 기기 20대까지 앱을 공유합니다. 무료이고 신분증이 필요 없습니다.

## 서명 키

- 정식 키 파일 `splittesla-release.jks`(별칭 `splittesla`)는 저장소에 넣지 않습니다. 잃어버리면 같은 앱으로 업데이트할 수 없으니 따로 백업해 두세요.
- CI는 저장소 Secrets 두 개로 서명합니다.
  - `SIGNING_KEYSTORE_BASE64`: 키 파일을 base64로 인코딩한 값
  - `SIGNING_KEYSTORE_PASSWORD`: 키 비밀번호
- Secrets가 없으면 예전 테스트 키(`app/debug.keystore`)로 서명하고 경고를 남깁니다.
- 인증서 SHA-256 지문:
  `85:64:A5:D6:D2:64:16:5E:A1:2E:2C:BB:0F:7C:86:10:12:4D:2F:96:97:10:88:48:78:26:32:C2:05:73:3A:52`

## 키를 바꿀 때 한 번 해야 하는 일

테스트 키로 설치된 앱 위에는 새 키 APK가 설치되지 않습니다.

1. 기존 앱을 삭제합니다. 폰에 저장된 차 키도 같이 지워집니다.
2. 새 APK를 설치합니다.
3. 앱에서 차 키를 다시 등록하고, 차 중앙 콘솔에 키카드를 대서 승인합니다.
4. 차의 잠금 > 키 목록에 남은 예전 폰 키는 지워도 됩니다.

## 제한 배포 계정 등록

1. [Android Developer Console](https://developer.android.com/developer-verification/guides/android-developer-console)에서 제한 배포(학생·취미) 계정을 만듭니다.
2. 앱 등록에 패키지명 `com.splittesla.app`과 위 SHA-256 지문을 넣습니다.
3. 소유 증명으로 콘솔이 주는 파일을 `app/src/main/assets/`에 넣고 새 키로 서명한 APK를 올립니다.
4. 콘솔 안내에 따라 공유할 기기(최대 20대)를 지정하고 APK를 보냅니다. 기기 추가 방식은 콘솔에서 확인이 필요합니다.

한국은 2027년 이후에 인증이 의무화되므로 그 전까지는 지금처럼 APK로도 설치됩니다.
