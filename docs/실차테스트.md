# 실차 테스트 가이드

## 준비

1. GitHub Actions 실행 결과에서 `SplitTesla-apk`를 내려받아 폰에 설치합니다 (출처를 알 수 없는 앱 허용 필요).
2. 앱 첫 실행 때 '근처 기기' 권한을 허용합니다.
3. S3XY 공식 앱은 완전히 종료합니다. Commander는 한 번에 한 폰만 붙는 경우가 많습니다.

## 1단계: S3XY Commander

1. 상단 `S3XY` 칩을 누릅니다.
2. '페어링 필요'가 뜨면 60초 안에 핸들 오른쪽 스크롤 버튼을 두 번 누릅니다.
3. 상태가 '연결됨'이 되고 대시보드에 속도·배터리 값이 들어오면 성공입니다.
4. `S3XY 동작` 탭에서 안전한 동작부터 시험합니다: 비상등, 미러 접기, 글러브박스.

확인할 것: 대시보드 값이 실제 계기판과 맞는지, 각 동작이 실제로 실행되는지.

## 2단계: 테슬라 공식 BLE

1. `설정·로그` 탭에서 VIN 17자리를 입력하고 저장합니다.
2. 차 안에서 상단 `차량 BLE` 칩을 누릅니다.
3. `키 등록 요청`을 누르고, 센터 콘솔 리더에 키 카드를 댄 뒤 차량 화면에서 승인합니다.
4. `핑 테스트`가 성공하면 `차량` 탭에서 잠금/해제, 충전 한도, 공조, 상태 조회를 시험합니다.

## 3단계: 내비

1. 차량 화면에서 목적지를 설정합니다.
2. `내비` 탭에서 `새로고침`을 누르면 목적지, 남은 시간·거리, 도착 시 배터리가 나와야 합니다.
3. `10초 자동 갱신`을 켜고 주행하며 값이 바뀌는지 봅니다. S3XY가 연결돼 있으면 제한속도도 나옵니다.
4. `주변 슈퍼차저` → `찾기`를 누르고, 항목을 누르면 폰 지도 앱으로 열립니다.

## 4단계: 과속카메라 알림

1. `내비` 탭 > `카메라 데이터 받기·갱신`에서 공공데이터 CSV를 가져오거나 인증키로 받습니다.
2. `과속카메라 알림`을 켜고 위치·알림 권한을 허용합니다.
3. 아는 카메라가 있는 길을 달려 봅니다. 시속 90km면 약 300m 전, 그리고 100m 전에 음성이 나와야 합니다.
4. 반대 차선 카메라에서 울리는지, 터널에서 끊기는지도 봐 주세요.

## 결과 보내기

`설정·로그` 탭의 `공유` 버튼으로 로그를 보내 주세요. 문제가 S3XY 쪽이면 '실시간 원본 패킷 로그'를 켠 뒤
재현한 로그가 있으면 좋습니다.

S3XY 연결이나 동작이 실패하면 다음 단계로 S3XY 공식 앱을 rea로 분석해 프로토콜 차이를 찾습니다.

## 5단계: Android 안내 안전성 회귀 (2026-11-04)

아래 항목은 구현 후 **아직 기기에서 실행하지 않은 체크리스트**입니다. 조작·기록은 동승자가 담당하고, 속도 위반을 유도하지 않습니다. SDK가 있는 환경에서 APK 빌드부터 확인합니다.

- [ ] BLE를 끈 상태에서 GPS 속도가 있는 정상 주행: 기존 카메라 조기/최종 알림 유지.
- [ ] 테스트용 Location 재생으로 hasSpeed=false/NaN 입력: 연속 실제 위치로 접근 경고가 나오되 “속도를 줄이세요”는 나오지 않음. 기기 실제 센서에 NaN을 억지로 만들 필요 없음.
- [ ] Commander 속도 수신 중단 후 UI의 다른 차량 값만 갱신: 마지막 속도의 시각이 새로워지지 않고3초 이후 DR에 사용되지 않음. Tesla nav 속도도 실제 nav 갱신 시각 기준 확인.
- [ ] 300m/목적지로 단발 점프, 순서 뒤바뀐/중복 fix, 정확도80m, 오래된 cached fix 재생: 진행·카메라 통과·구간 평균·도착 확정 없음.
- [ ] 서로 무관한 반복 튐과40m 왕복 후보: 횟수만으로 재획득하지 않음. 정상 궤적 복귀와5초 이상 일관된 새 궤적 재획득, 정지 상태 재획득도 각각 확인.
- [ ] 터널 무수신 + 신선한 차량 속도:3초 이후 추정 표시/진행, 마지막 실제 fix 이후30초 이내에 전진 중단. BLE 속도까지 끊으면3초 내 중단. 터널 중 arrived/자동 종료/가상 카메라 통과/평균 확정 없음.
- [ ] 터널 출구 실제 fix가 추정 위치 뒤에 나타날 때 진행 복구. 급커브·루프·고가/지하 겹침에서 먼 세그먼트로 단발 전진하지 않는지 확인.
- [ ] 목적지 실제40m 이내/경로 남음30m 미만/양호한 GPS 두 번(0.5초 이상 간격)에서 도착 문구 한 번.15초 종료 대기 중 목적지를 떠나거나 GPS를 끄면 안내가 무조건 끝나지 않음.
- [ ] 안내 중 경로 카메라0개인 구간 및 경로 로딩 중: 옆 도로 전체 카메라로 폴백하지 않음. 안내 종료/실제 경로 이탈 뒤에는 기존 주변 공공카메라 경고가 다시 작동.
- [ ] 카메라 최초 감지가42m인 재생: “40미터 앞” 문구. 고정100m 문구 없음.
- [ ] 단순 START/END 순서·가까운 좌표만 있는 구간: 평균 수치 없음, 실제 종료 지점에서는 “평균 속도 미확인”. unrelated END로 다른 확실한 구간을 종료하지 않음(확실한 짝은 테스트 fixture에서만 주입).
- [ ] START 앞에 멈추거나 카메라 필터 변경: 카메라가 사라졌다는 이유만으로 구간 시작/통과 처리하지 않음.
- [ ] 자동 재탐색 실패를 반복: 시작 문구는 이탈 에피소드당 한 번,15/30/60초 재시도 간격, 성공 시 두 번째 문구 없음. 수동 재탐색/경유지 성공 문구는 기존 유지.
- [ ] 기존 방향 무시·학습·도로 제한 확인·보호구역 설정 유지. 단방향 카메라가 경로 왼쪽7m 초과면 기존대로 제외되는 한계와 방향 코드1/2의 방위각 미상을 기록.
- [ ] 카메라+턴+어시스턴트 동시 발화 여부 별도 기록: 단일 TTS는 후속 단계이므로 이번 수정으로 해결됐다고 판정하지 않음. 음악 ducking/음성인식 stop/서비스 종료 및 재시작도 후속 QA.

각 결과에는 앱 버전, 기기/Android 버전, 샘플 시각·정확도·속도 출처, 재현 순서, 기대/실제 음성, 통과/실패를 기록합니다. 위치 로그를 공유하기 전 개인 목적지·차량 식별자를 제거합니다.
